# CLAUDE.md

Инструкции по проекту: как устроен сайт, как добавлять контент, деплой и домен.
Короткое описание для людей — в README.md.

Личный сайт **azh.** на [Astro](https://astro.build): заметки, книжные полки, находки, about и скрытая страница `/cv`. Два языка: английский в корне, русский под `/ru/`.

## Запуск на своём компьютере

Нужен Node.js 22 или новее (`brew install node`).

```bash
npm install
npm run dev      # http://localhost:4321, обновляется при сохранении
npm run build    # собирает готовый сайт в папку dist/
npm run check    # проверка типов и схем контента
```

## Как добавлять контент

Весь контент — это Markdown-файлы в `src/content/`. Один файл = одна запись. Имя файла становится адресом: `books/dune.md` → `/bookshelves/books/dune/`.

Картинки кладутся рядом с `.md` и указываются относительным путём (`cover: ./dune.jpg`). Astro сам сожмёт их в нужные размеры. Если обложки нет, рисуется «самодельная» цветная обложка.

У каждой записи есть необязательные поля `tags: [a, b]` и `lang: ru` (для текстов на русском).

### Заметка — `src/content/notes/`

```md
---
title: Необязательный заголовок
date: 2026-11-02
tags: [ml, qa]
lang: ru
---

Текст заметки в Markdown. Без заголовка в списке покажется сам текст.
```

`draft: true` — заметка видна только в `npm run dev`.

### Книга — `src/content/books/`

```md
---
title: Название
author: Автор
cover: ./covers/slug.jpg   # картинка в src/content/books/covers/
status: reading        # reading | read | want-to-read | dnf
rating: 8              # 1–10, необязательно
plan: 2027             # необязательно: книга из плана на год
startDate: 2026-10-01
finishDate: 2026-10-20
note: Пара строк впечатлений.
quotes:
  - "Цитата"
---

Необязательная полная рецензия.
```

Обложки лежат в `src/content/books/covers/`, по файлу на книгу, шириной до 640 px. Без обложки рисуется самодельная.

**Планы на год.** Книга со статусом `want-to-read` и полем `plan: 2027` попадает в блок «Планы на 2027» сразу после «Читаю сейчас». Под заголовком — полоска «прочитано N из M»: она считает все книги с этим `plan`, включая уже прочитанные. Когда дочитаешь книгу из плана, поменяй статус на `read` и оставь `plan` — книга уйдёт в свой месяц, но продолжит считаться в прогрессе.

### Курс — `src/content/courses/`

Поля: `title`, `instructor`, `platform`, `cover`, `status` (learning | completed | want-to-take | paused | dropped), `rating`, `startDate`, `completionDate`, `note`, `learned` (список), `url`. Текст файла — заметки по курсу.

### Фильмы и сериалы (сейчас скрыты)

Разделы Movies и TV Shows выключены. Чтобы вернуть, удали строку `hidden: true` у нужной категории в `src/utils/shelves.ts`.

### Фильм — `src/content/movies/`

Поля: `title`, `year`, `poster`, `director`, `status` (watched | want-to-watch), `rating`, `watchedDate`, `note`. Текст — рецензия.

### Сериал — `src/content/tv-shows/`

Поля: `title`, `year`, `poster`, `status` (watching | finished | want-to-watch | on-hold | dropped), `rating`, `startDate`, `finishDate`, `season`, `note`.

### Находка — `src/content/things/`

Поля: `title`, `description`, `image` + `imageAlt`, `url`, `date`, `featured: true` (показывать на главной).

### Рецепт — `src/content/recipes/`

```md
---
title: Муравейник по бабушкиному рецепту
description: Одна строка для карточки.
date: 2026-11-12
image: ./photo.jpg        # необязательно; без фото — цветная карточка с тортиком
time: 2 часа              # необязательно, свободный текст
servings: 1 торт          # необязательно, свободный текст
ingredients:
  - group: Тесто          # группа необязательна
    items:
      - 2 яйца
steps:
  - Первый шаг.
tags: [десерт]
lang: ru
---

Необязательная история рецепта или советы.
```

Перевод — как у остальных, в `translations/en/recipes/<id>.md`: `title`, `description`, `ingredients`, `steps`, `time`, `servings` целиком на другом языке.

### Даты без числа

Если помнишь только месяц, пиши дату как `2026-06`: на сайте она покажется как «Jun 2026». Работает для `finishDate`, `startDate` и других дат книг и курсов.

### Тексты страниц — `src/content/pages/`

- `home.md` — приветствие на главной;
- `about.md` — страница About;
- `cv.md` — резюме на `/cv` (нет в меню и в sitemap, закрыто от поисковиков). Чтобы появилась кнопка «Download PDF», положи файл в `public/cv.pdf` (для русской версии — `public/cv-ru.pdf`).

### Два языка

Сайт на двух языках: английский в корне (`/notes/`), русский под `/ru/` (`/ru/notes/`). Переключатель EN · RU в шапке открывает ту же страницу на другом языке.

- **Интерфейс** (меню, кнопки, подписи, статусы, названия месяцев) — в `src/i18n/ui.ts`. Там же подписи тегов: тег пишется в файле один раз (например, `детектив`), а на английской версии показывается как `#mystery`. Новый тег без перевода показывается как есть.
- **Контент** пишется один раз на своём языке (поле `lang`, по умолчанию `en`). Перевод лежит рядом, в `src/content/translations/<язык>/<раздел>/<тот же id>.md`. В нём только переводимые поля и текст:

```md
---
title: The Likeness
author: Tana French
quotes:
  - "..."
---

Рецензия на английском.
```

Статус, оценка, даты и теги в перевод не копируются: они берутся из основного файла. Если перевода нет, показывается оригинал с пометкой, на каком он языке.

Примеры: книга `books/shodstvo.md` (русская) → `translations/en/books/shodstvo.md`; страница `pages/about.md` (английская) → `translations/ru/pages/about.md`. Ссылки внутри русских текстов пиши с префиксом: `/ru/bookshelves/`.

### Демо-контент

Оставшиеся файлы `demo-*` (книги, курсы) — заглушки с пометкой `demo`. Удали их, когда появится свой контент. Пустые разделы покажут дружелюбную пустую полку. Файлы `.gitkeep` в пустых папках не трогай: без них git не сохранит папку.

## Деплой на GitHub Pages

1. Создай на GitHub репозиторий с именем **`<твой-логин>.github.io`**. Тогда сайт будет жить в корне адреса, и ссылки не сломаются.
2. Залей проект:
   ```bash
   git init
   git add .
   git commit -m "azh. first version"
   git branch -M main
   git remote add origin git@github.com:<логин>/<логин>.github.io.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. Готово: каждый `git push` в `main` пересобирает и публикует сайт (`.github/workflows/deploy.yml`). Прогресс виден во вкладке Actions.

## Свой домен

1. Купи домен у любого регистратора.
2. В репозитории: **Settings → Pages → Custom domain**, впиши домен и сохрани.
3. У регистратора настрой DNS:
   - для домена без `www` — четыре A-записи на адреса GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - для `www` — CNAME на `<логин>.github.io`.
4. Когда DNS обновится (от минут до суток), включи **Enforce HTTPS** там же.

Актуальная инструкция: [docs.github.com — custom domain for GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).

Адрес сайта для canonical-ссылок, sitemap и RSS workflow берёт из настроек Pages сам, менять код не нужно.

## Структура

```
src/
├── content/           контент (Markdown), переводы в content/translations/
├── content.config.ts  схемы: какие поля бывают у записей
├── components/        переиспользуемые блоки (карточки, бейджи, шапка…)
├── i18n/              языки: строки интерфейса, подстановка переводов, пути
├── layouts/           общий каркас страницы, SEO-теги
├── pages/             маршруты сайта: тонкие обёртки, русские — в pages/ru/
├── views/             сами страницы, общие для обоих языков
├── styles/            tokens.css (цвета, шрифты, отступы), global.css, typography.css
└── utils/             логика полок, даты, выдержки
```

Все цвета, шрифты и отступы задаются переменными в `src/styles/tokens.css`. Тёмную тему можно будет добавить, переопределив только цвета.

## Отступления от спецификации

- **Хостинг** — GitHub Pages вместо Cloudflare Pages: с июня 2025 российские провайдеры ограничивают доступ к сайтам за Cloudflare.
- **Сетка обложек**: 2 колонки на телефоне, 3 на планшете, 4 на десктопе (в спеке 2/2/3). При 2–3 колонках обложки получаются огромными.
- **`--color-muted`**: `#6B6A63` вместо `#77766F`. Исходный цвет не проходит контраст WCAG AA на фоне `--color-paper`.
- **Кириллица в заголовках**: в Bricolage Grotesque нет кириллицы, поэтому русские заголовки рисуются шрифтом Inter. Латиница остаётся в Bricolage.
- **Поиск и фильтры** на полках — небольшой скрипт без библиотек. Без JavaScript всё просто показывается целиком.
